# Mom's Safety Guide: Using the Automation System

**Version:** 1.0  
**Last Updated:** December 14, 2025

This guide explains the special safety features we built to make sure the automation never makes a mess of your accounting.

---

## 1. The "Traffic Light" System (Visual Pause)

We know computers can be too fast. That's scary.
So, we taught this system to act like a polite human, not a robot.

**How it works:**

1. **Move:** The mouse pointer moves to a box (like "Vendor Name").
2. **Wait:** It **STOPS** there for a full second (1.0s).
3. **Type:** Only *after* waiting does it type the text.

**Why this helps you:**
If you see the mouse move to the wrong place, you have time to stop it! You don't have to race the computer.

---

## 2. The Blue "I'm Thinking" Box

You never have to guess what the computer is doing.
At the very top of your screen, a **Blue Box** will appear whenever the automation is working.

It will say things like:

* *"Typing Invoice Number..."*
* *"Entering Total Amount..."*

**Tip:** If the Blue Box says "Entering Tax" but the mouse is on the "Address" line, **press F12 immediately!**

---

## 3. The "Oh No!" Button (F12)

This is your emergency brake. You can press it at **ANY TIME**.

* **Key:** `F12` (Top right of your keyboard)
* **What happens:** The automation **STOPS INSTANTLY**.
  * It stops typing.
  * It stops moving the mouse.
  * It cancels whatever it was doing.

**When to use it:**

* If the mouse is in the wrong field.
* If the computer starts typing gibberish.
* If you just want to take over manual control.

---

## 4. The Red "Emergency Stop" Screen

After you press **F12**, or if the system runs into a serious error, a **Big Red Window** will pop up on the dashboard.

It will tell you: **"EMERGENCY STOPPED"**

You have two choices:

### Option A: "I Fixed It - Resume" (Grey Button)

Use this if you fixed the problem manually.

* *Example:* The mouse triggered a popup menu. You closed the menu manually. Now you want the robot to finish the rest of the invoice.

### Option B: "ABORT EVERYTHING" (Red Button)

Use this if you want to give up on this invoice completely.

* The system will stop.
* You can restart the invoice from the beginning later.

---

## 5. The Golden Rule: "I Never Save"

The most important safety feature is what the system **DOES NOT** do.

* **The automation will NEVER click "Save" in ACSoft.**
* It will fill in the form, and then it will sit there and wait for you.

**Your Job:**

1. Look at the screen. Does it look right?
2. If yes -> **YOU click Save.**
3. If no -> **YOU click Cancel** (or fix it).

This means **no bad data** can ever get into your accounting books without your final approval.
